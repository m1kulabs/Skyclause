> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. **Goal:** Deliver the real APIMS adapter with one all-bound latest request per slot, isolated station errors and honest state-grouped history.

**Architecture:** Extend the current runner through opt-in capabilities, keeping legacy JPS behavior. Execute each history step as an independently captured immutable result under one durable state claim. Feed-slot admission and plan-driven eligibility remain database-free on scheduled paths; the existing 15-minute ingest batch owns domain writes.

**Tech stack:** Existing TypeScript, Zod, Vitest, PostgreSQL/Drizzle, GCS generation CAS, Pub/Sub and Terraform. No new runtime dependencies.

**Spec:** [APIMS design](/docs/superpowers/specs/2026-11-10-apims-adapter-design.md). Baseline `69b77ded9dc4fb3635012694ee8410a7a928bd6d`, `/Users/jeremywoon/.codex/worktrees/2d2a/gdgocapu`.
