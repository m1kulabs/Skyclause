## Review Focus

1. Partial invalid stations must retain valid peers, while structural corruption must append no reading from that response. Task 1 covers both and Task 2 verifies the persisted result.
2. An ignored history datetime must not import recent records as old history. Task 1 uses the preserved invalid-hour response and strict inclusive bounds.
3. A history correction may change the numeric value without carrying a class. Task 2 pins changed-revision metadata and unchanged-overlap class preservation.
4. A checkpoint failure, slow request or crossed 06:00 boundary must neither drop the other hours nor starve later states. Task 2 exercises persisted-then-thrown writes, frozen plans and durable fair attempt ordering.
5. A successful aggregate poll must not make a missing station look healthy. Task 3 joins only actual station reading/poll pairs and preserves other source health behavior.
