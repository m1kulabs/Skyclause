## Review focus

1. A successful `[]` warning payload remains a legitimate no-reading poll; HTML, error objects, missing fields and invalid timestamps fail with no fabricated No Advisory. Test in Tasks 1 and 3.
2. Two warnings share issue time but remain separate items; whitespace, Unicode and nullable instructions survive storage, and same-key corrections append only one revision. Test in Tasks 1 and 3.
3. A broad Kuala Lumpur substring response contains three location IDs; only the bound external ID contributes, missing bound data fails its source, and unknown phrases receive no invented gloss. Test in Tasks 1 and 3.
4. Discovery competes with polls/probes in the exact same durable weather-family budget; denied admission never performs HTTP, and malformed catalogue data never upserts. Test in Task 2.
5. Existing reducer shortcuts must not masquerade as proof: null validity, exclusions and non-Kuala-Lumpur project terms follow the actual contract; expired retained records cannot become current warnings. Test the pure predicate in Task 1 and the actual corrected engine in Task 3.
