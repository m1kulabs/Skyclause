Technical Architecture

Built, Not MockedMore than 4,400 automated tests pass, many on stored captures of the public feeds.
09 / 11 · Technical ArchitectureCloud Run · Cloud Scheduler · Pub/Sub · Cloud Tasks · Vertex AI · Secret Manager · KMS · Resend
Cloud Scheduler runs the source adapters on Cloud Run. A Raspberry Pi 5 and a phone camera can add local readings: their agents are built, and platform ingest is next. The clause engine checks every window, and Gemini on Vertex AI drafts the call. One person approves in the web app, and the notice goes out by email and calendar. Every call is sealed in the ledger.
